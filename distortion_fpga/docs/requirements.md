# 题目要求与验收证据

原始依据：工作区根目录《2026FPGA赛道选题指南-紫光同创.pdf》，物理第12–14页（印刷页10–12）；MES50HP平台介绍在物理第6页。以下是项目拆解，不是主办方另行发布的评分阈值。

|要求|实现路径|验收证据|
|---|---|---|
|视频采集、缓存、显示|MES50HP厂商摄像头/HDMI和DDR例程接入|真实视频、丢帧/溢出计数、示波器或ILA|
|k1、k2径向与p1、p2切向畸变|FPGA按输出坐标逆向采样，内部执行畸变多项式|独立OpenCV坐标对照、RTL逐位对拍|
|图像插值|RGB888四点双线性，8位小数权重|整数/半像素/边界/随机像素验证|
|内参及畸变参数解析|真实标定JSON与定点寄存器导出；帧开始锁存|参数导出检查、处理中修改配置不影响本帧|
|标定数据真实|固定k3=0拟合题目规定模型，保存逐视图误差|真实图片、采集设置、校准文件和独立测试图|
|清晰度及几何质量|坐标误差、直线残差、后续斜边SFR/MTF50|真实图卡报告，不能以合成图替代|
|实时性能（如1080p30/60）|流水线数学核＋DDR突发缓存和视频FIFO|PDS时序、实际帧率、端到端硬件延迟|
|资源及CDC|板级资源预算、跨时钟FIFO、帧缓冲所有权|PDS资源报告、CDC审计、溢出监测|
|高阶动态角度|预留输出像素到理想归一化平面的逆仿射矩阵|帧边界动态切换测试；3D透视另需齐次除法|
|高阶增强|后续Gamma LUT/曝光统计模块|暗光/强光实拍对照|

现阶段用户没有硬件。离线交付覆盖算法、定点格式、可综合模块、抽象内存帧处理和仿真；不构成视频物理链路、PDS收敛或真实相机精度的验收。

## 不混淆的概念

- **逆向采样**：遍历输出网格，通过畸变模型求原图的取样位置；避免正向散射导致空洞。FPGA仍实际计算径向和切向多项式。
- **黑边**：映射落在相机视野外时没有对应信息，插值无法恢复；逐邻点补零是可验证的边界定义，展示时可用有效ROI/适当缩放裁切。
- **任意角度**：当前逆仿射可表达平面旋转/缩放/平移；相机三维俯仰与透视矫正还需要齐次变换及除法，不能混称已经实现。
- **吞吐量**：数学流水线每周期接受一个坐标，不代表串行访存集成核每周期输出一个像素，也不等于整机达到1080p。

## 必须保留的后续材料

真实镜头型号、固定的分辨率/焦距/对焦状态、多姿态标定图、留出测试图、实际板卡版本、PDS版本和IP版本、综合/时序报告、实测视频及延迟测量方法。
