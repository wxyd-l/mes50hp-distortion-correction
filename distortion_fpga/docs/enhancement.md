# 流式自适应 Gamma 预处理

原始选题指南物理第12页要求在矫正前或矫正过程中集成自适应 Gamma 或直方图均衡。实现选择**源 RGB888 → Gamma → 源帧存储 → 坐标映射/四邻读取/双线性插值**。统计每个原始像素一次；不得对重复读取的四邻像素统计，也不得把矫正产生的黑边加入曝光统计。Gamma 与插值不交换顺序，软件及 RTL 集成必须使用增强后的源帧。

## 数值定义

七个 bank 为 `0.5, 0.65, 0.8, 1.0, 1.25, 1.5, 2.0`，编号0–6。对每个通道输入 `x∈[0,255]`，输出为 `floor(255*(x/255)^gamma+0.5)`。指数小于1提亮，大于1压暗。`rtl/gamma_lut.hex` 是7×256×8位的小查找表，保存人工选定的色调函数，并非几何全图查表。bank3逐值恒等；所有bank单调且保持0、255端点。

统计使用尚未增强的 RGB：`Y=(77R+150G+29B+128)>>8`。40位无符号亮度总和、32位无符号像素计数覆盖不超过 `2^32−1` 个像素的帧。亮度权重和各阈值乘积在 RTL 中均通过移位加法实现，无除法、对数、幂运算或乘法器。阈值比较直接使用总和与像素数的乘积，避免整数均值造成额外量化。

原始均值的六个分界是32、64、96、160、192、224；无滞回时，七个由低到高的区间分别选择bank0–6。目标bank有±4级滞回：处于目标bank `t` 时，均值在 `[原下界−4,原上界+4)` 内保留该目标，越出后按上述名义分界重选。两端区间无外侧边界。滞回基于**目标bank**，不是尚在追赶的应用bank。

当前帧的原始统计决定下一帧的目标，每帧应用bank向目标最多移动一档。因此不会把“原始图一直暗”误当成反馈不足而持续积累增益。参数是可复现的初始工程选择；真实镜头、场景和相机自身曝光行为确定后可比较档位及响应速度。

## 帧与接口

`gamma_stream` 是单时钟、一级弹性寄存的流模块。`in_valid && in_ready` 接受一个像素，`in_ready = !out_valid || out_ready`。输出受阻时 RGB、bank、SOF、EOF 一起保持。无背压时可每周期接收一个像素，经过一个寄存级输出。

|接口|语义|
|---|---|
|`cfg_mode[1:0]`|0旁路；1固定；2自适应；3按旁路处理|
|`cfg_bank[2:0]`|固定bank；硬件值7夹到6；软件API只接受0–6|
|`in_rgb[23:0]`|R占23:16、G占15:8、B占7:0|
|`in_sof`, `in_eof`|第一、最后一个有效像素的标志；单像素帧同时置1|
|`out_rgb`, `out_bank`, `out_sof`, `out_eof`|与`out_valid/out_ready`一起消费|
|`stats_valid`, `stats_sum[39:0]`, `stats_count[31:0]`|接受EOF的时钟沿更新，`stats_valid`持续一个周期，含最后像素|

配置仅在接受SOF的时钟沿锁存，该首像素即应用新配置，帧内配置变化不生效。输入每帧提供一对SOF/EOF；SOF清零累加器后计入首像素。统计输出没有反压，其消费者每周期均可接收；相邻单像素帧可以每周期给出一组统计。

复位清除流水线和统计并令目标/下一bank为3。进入自适应模式的第一帧恒等bank3；随后连续自适应帧使用上一帧产生的下一bank。退出自适应后再进入，重新从bank3启动。固定模式和旁路同样输出原始统计，但不把其目标状态沿用到新的自适应会话。

`software/enhancement.py` 提供 `GAMMAS`、`gamma_lut(bank)`、`apply_gamma(image,bank)`、`luma_u8(image)`、`select_target(sum,count,previous_target)`、`GammaFrameState`（别名`FrameGammaState`）。`state.process(rgb,mode='adaptive',bank=3)` 返回增强图及 `used_bank/next_bank/target_bank/raw_sum/raw_count/raw_mean/gamma` 等报告字段。输入是RGB顺序uint8，OpenCV BGR读入后先转换。`LUT_FILE` 默认相对于项目根目录的 `rtl/gamma_lut.hex`；在其他综合工作目录使用绝对路径参数或复制ROM并设置路径。

## 颜色效果与判别实验

相同函数逐通道应用保持中性灰、端点及通道排序，但会改变彩色像素的色相及饱和度。`scripts/generate_gamma.py` 使用12块明确列出的合成RGB色块，其中9块有色，输出逐块数值至 `build/gamma_color_report.json`。HSV圆周色相差只在这9块上统计：

|Gamma|色相平均绝对差/最大差（度）|输入(180,70,30)的输出|
|---|---|---|
|0.5|7.68 / 12.47|(214,134,87)|
|0.65|5.16 / 8.24|(203,110,63)|
|0.8|2.87 / 4.47|(193,91,46)|
|1.0|0.00 / 0.00|(180,70,30)|
|1.25|3.16 / 4.71|(165,51,18)|
|1.5|5.86 / 8.71|(151,37,10)|
|2.0|10.80 / 15.06|(127,19,4)|

这是合成像素算术结果，不是实拍或色度计测量。色块中任一通道为255的比例为25%，每档输出仍为25%；已剪裁的高光、全黑像素并不会恢复纹理。均值控制也不能辨认低照度场景与本来就黑的物体，因此提供固定/旁路对照；真实场景验证应查看局部细节和颜色，而不能仅把输出均值靠近中间值视作效果成功。

能区分控制逻辑错误的短序列是连续10帧均匀灰32、再10帧灰224。应用bank依次应为 `[3,2,1,1,1,1,1,1,1,1]` 和 `[1,2,3,4,5,6,6,6,6,6]`。若恒灰32继续降到bank0，说明把原始亮度误用作积分类反馈。另以99→100与92→91均值跨越滞回边界，并在帧内改变配置，区分滞回状态错误与帧锁存错误。

## 可复现验证

在 `distortion_fpga` 根目录运行：

```text
python scripts/generate_gamma.py
python -m unittest discover -s tests -p test_enhancement.py -v
python scripts/run_hdl.py --only gamma
python scripts/check_synthesis.py --top gamma_stream
```

专用数值测试覆盖全部1792 LUT条目、亮度权重、中性灰、恒场景收敛、精确分数阈值、模式切换及饱和端点。`sim/tb_gamma.sv` 的2556像素/48帧向量对拍覆盖全部七bank输入值、输入空拍、输出背压、逐帧配置、帧内配置扰动、首末同像素及每帧原始统计。实际Icarus仿真已通过；Yosys通用结构检查得到零问题、零锁存器、零通用乘法单元、186寄存器位及14336 ROM位。

该ROM有三个组合读端口；PDS可能复制或映射为逻辑，不能据通用ROM位数直接声称占用一个片上RAM。Pango映射、最高时钟和真实摄像头效果应由对应工具/硬件结果填写。
